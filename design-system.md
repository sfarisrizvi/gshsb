# Website Design Specification

## Overview
This document outlines the design language and stylistic direction for the website, focusing on a premium, high-tech, and immersive user experience.

## Brand Identity & Typography
*   **Heading Font:** CC EPIC PRO
*   **Body Font:** Outfit (Regular)

## Color Palette
The design leverages a high-contrast dark theme with vibrant orange accents for a modern, energetic feel.

| Element | Color Code |
| :--- | :--- |
| **Accent** | `#e46222` |
| **Gradient Accent 2** | `#520701` |
| **Background (BG)** | `#000000` |
| **Text** | Dynamic (`#ffffff` to `#4c4c4c`) |

## Stylistic Elements
*   **UI Style:** Glass morphism (blur, transparency, and subtle borders).
*   **Shapes:** Rounded corners and organic, soft UI shapes throughout the interface.
*   **Visual Direction:** Inspired by high-end, image-heavy layouts that balance technical information with cinematic storytelling.

## Design References
*   **Ref 1:** Fire safety solutions layout featuring image-heavy sections, card-based statistics, and clear CTA integration.
*   **Ref 2:** Sophisticated, typography-focused layout emphasizing brand heritage and high-quality imagery with minimalist navigation.



Here is a detailed breakdown of the UI design and layout inspired by your provided references and specifications:

## Overall Aesthetic & Theme

* **Visual Style:** Modern glass morphism utilizing backdrop filters, translucent layers, and subtle border highlights against a deep pure black background (`#000000`).
* **Geometry:** Rounded shapes and soft, organic container curves throughout the interface elements.
* **Color Harmony:** High contrast driven by dynamic text scaling from pure white (`#ffffff`) down to muted gray (`#4c4c4c`), punctuated by a vibrant primary accent (`#e46222`) and a deep gradient accent (`#520701`).

## Typography Hierarchy

* **Headings:** Rendered in **CC EPIC PRO**, giving titles and section headers a bold, impactful, and cinematic presence.
* **Body Copy:** Set in **Outfit Regular** to ensure high legibility, clean geometric forms, and seamless readability across data cards and descriptive blocks.

## Layout Components & Structure

* **Hero Section:** A dark, immersive opening screen featuring prominent typography, high-impact imagery (drawing from the cinematic styling of Reference 2), and primary action triggers styled with the bright accent color (`#e46222`).
* **Grid & Card Modules:** Content is broken down into modular, rounded cards featuring semi-transparent glass backgrounds, soft drop shadows, and delicate borders to separate data cleanly from the black canvas.
* **Interactive Elements & CTAs:** Buttons and interactive triggers transition smoothly, utilizing gradient washes (incorporating `#520701`) and solid orange highlights (`#e46222`) to draw user focus.
* **Media Integration:** Dedicated image and video frames with rounded borders that frame visual elements effectively, matching the structured narrative layouts seen in Reference 1.
